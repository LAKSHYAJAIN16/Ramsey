# Desktop behavior

`main.js` coordinates the interface; `api.js` handles backend calls; `firebase-auth.js` handles identity; `session-controls.js` handles session setup; `state.js` and `ui.js` manage/render UI state; `voice.js` captures audio.

Follow recipe selection through the API before inspecting headset pairing. Provider keys must never be embedded here. CI checks syntax, not full browser behavior. [Companion overview](../README.md).
