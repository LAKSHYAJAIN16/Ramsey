# Team plan

Ownership is unassigned until the team confirms who is doing each workstream.

| Workstream | Deliverable | Handoff check |
| --- | --- | --- |
| Backend | Reliable authenticated recipe/session APIs | Offline tests pass; provider errors remain visible |
| Quest | Paired passthrough cooking flow | Actual headset rehearsal, including reconnect |
| Desktop | Sign-in, real recipe selection, session setup | Selected recipe reaches the same Quest session |
| AI and perception | Contextual voice and bounded visual assistance | Unknown observations do not silently advance steps |
| Demo and documentation | Accurate deck, sources, build instructions | Every live claim matches a rehearsed path |

First priority is one complete recipe journey. Expand only after that path is dependable.
