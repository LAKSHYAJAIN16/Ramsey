# Unity assets

[Ramsey](Ramsey/README.md) contains the product-specific scene and code. Other folders contain Unity/Meta templates, XR configuration, input actions, and generated/imported setup assets.

Preserve `.meta` files: they carry the GUIDs connecting scenes, scripts and settings. The root project validator checks their presence. Third-party/template trees retain upstream organization; do not confuse them with original Ramsey functionality.
