# Unity dependencies

`manifest.json` declares packages; `packages-lock.json` records resolution. Meta XR Core, Interaction SDK, MR Utility Kit and OpenXR support the Quest app. The embedded `com.coplaydev.unity-mcp` package is development tooling, with its upstream license included.

Unity Package Manager restores registry dependencies on first open. Do not add Library/PackageCache. See [sources](../../SOURCES.md) and [project setup](../README.md).
